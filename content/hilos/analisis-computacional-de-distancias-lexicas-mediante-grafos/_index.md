Este es un trabajo de investigacion correspondiente a la catedra de Ingles Tecnico II de mis carreras en curso, Analista en Sistemas de Computacion y Licenciatura en Sistemas de Informacion. Si bien este trabajo es de ambito academico, lo tratare con cierta **informalidad** en este medio para centrarme en una forma de documentar de manera casual los avances que se hagan en el trabajo.

El proposito de este trabajo es el **estudio de un grafo ponderado de distancias lexicas mediante aplicaciones de algoritmos de grafos**. Se usa como base la **distancia de Levenshtein** para calcular las distancias entre palabras; se estudian ciertas palabras elementales en todos los lenguajes y se comparan mediante levenshtein para abstraer dichas comparaciones a un grafo.

**El enfoque de este trabajo es computacional**, por lo que el interes radica en la propia abstraccion de la informacion en esta estructura de datos y en la aplicacion de algoritmos para estudiar el comportamiento de este grafo. Cuestiones linguisticas soportan el contexto en el que se desarrolla el trabajo, mas son de interes secundario para lo que se quiere estudiar.
